# 쉬운말 도우미 (easy-korean)

> 공문서 사진 한 장을 **쉬운 한국어**와 **해야 할 일**로 바꿔주는 AI 에이전트
> 제4회 경남 AI·SW 경진대회 출품작

- 배포 주소: https://easy-korean.streamlit.app (입장 비밀번호 필요)
- 대상: 농인 (한국수어를 일상어로 쓰는 청각장애인)

## 왜 만들었나

농인에게 한국수어는 제1언어이고, 한국어 글은 제2언어입니다. 글자는 읽을 수 있어도 한자어가 많고 문장이 긴 공문서·고지서·안내문은 이해하기 어렵습니다.
수어 번역은 연구가 많지만, **한국어 문서를 쉬운 한국어로 풀어주는 도구**는 거의 없습니다.

쉬운말 도우미는 수어 번역이 아니라 쉬운 한국어 변환을 택했습니다.

- 수어는 일상에서 쓰는 글자가 없어 글로 보여줄 수 없습니다.
- 행정 용어는 표준 수어가 없는 경우가 많아 결국 개념을 풀어서 설명해야 합니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 사진 → 쉬운 한국어 | 문서 사진이나 글을 `[해야 할 일]` · `[쉬운 설명]` · `[어려운 말 풀이]`로 바꿉니다. 해야 할 일은 언제까지 · 어디로 · 무엇을 · 얼마를로 정리합니다. |
| 원문 대조 검증 | 결과의 날짜·금액·번호를 원문과 **두 방향**으로 대조합니다. 빠진 값(정방향)과 지어낸 값(역방향)이 있으면 화면에 경고합니다. |
| 도움 고르기 (에이전트) | AI가 문서에 맞는 도움을 고릅니다. 📅 폰 캘린더 일정 파일, ✉️ 기관에 보낼 문의 문장과 107 손말이음센터 안내, ✅ 준비물 체크리스트 |
| 묻고 답하기 | 문서에 대해 최대 5번 질문할 수 있습니다. 답에 원문에 없는 값이 있으면 경고합니다. |
| 개인정보 가리기 | AI 표시와 코드 규칙으로 두 번 가립니다. 서버에 아무 파일도 저장하지 않습니다. |

## 처리 흐름

```
사진 준비 → 글자 읽기 → 개인정보 가리기 → 쉬운 한국어 변환 → 원문 대조 검증 → 도움 고르기 → 묻고 답하기
 (코드)      (AI)          (코드)              (AI)              (코드)           (AI + 코드)    (AI + 코드)
```

핵심 원칙은 **AI는 판단하고, 코드가 실행하고 검증한다**입니다.

- 글자 읽기는 보이는 그대로만 옮기고, 읽을 수 없으면 `[판독불가]`로 씁니다.
- 개인정보 가리기와 원문 대조 검증은 AI 없이 코드 규칙만 써서 매번 같은 결과를 냅니다.
- AI가 고른 날짜·번호·준비물은 코드가 원문과 대조해서, 원문에 없으면 버립니다.
- 글을 붙여 넣으면 글자 읽기 대신 이름·주소 찾기 단계를 거칩니다.

## 시작하기 (내 컴퓨터에서 실행)

Python 3.9~3.13이 필요합니다.

**1. 라이브러리 설치**

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**2. 비밀 설정 만들기**

`.streamlit/secrets.toml.example`을 복사해서 `.streamlit/secrets.toml`을 만들고 실제 값을 넣습니다.

```toml
ANTHROPIC_API_KEY = "sk-ant-..."
APP_PASSWORD = "입장-비밀번호"
```

- `APP_PASSWORD`가 없으면 아무도 화면에 들어갈 수 없습니다.
- `secrets.toml`과 `.env`는 git에 올라가지 않습니다(`.gitignore`). API 키를 코드나 화면에 남기지 마세요.

**3. 웹 화면 실행**

```bash
streamlit run app.py
```

브라우저에서 http://localhost:8501 을 열고 비밀번호를 입력합니다.

### 터미널에서 변환하기 (선택)

화면 없이 파일을 변환할 수도 있습니다. 이때는 `.env.example`을 복사해 `.env`를 만들고 API 키를 넣습니다.

변환할 파일을 `samples/` 폴더에 넣고 파일 이름만 적습니다.

```bash
python convert.py notice.txt       # 글 파일
python convert.py notice.jpg       # 사진 파일 (jpg, jpeg, png, heic)
```

결과는 `samples/results/`에 `_original.txt`(가린 원문)와 `_result.txt`(결과)로 저장됩니다. 터미널 변환은 변환·검증까지만 하고, 도움 고르기와 묻고 답하기는 웹 화면에서만 동작합니다.
`samples/` 폴더는 개인정보 보호를 위해 git에 올리지 않습니다.

API 연결만 확인하려면 `python test_connection.py`를 실행합니다. (실제 API를 1번 호출합니다)

## 테스트

```bash
pip install -r requirements-dev.txt
python -m pytest
```

- 테스트는 **가짜 AI 응답**만 쓰고 실제 인터넷 요청은 막혀 있어서, 실행해도 API 비용이 들지 않습니다.
- 테스트 데이터는 모두 가짜 이름·주소·번호입니다.

| 파일 | 확인하는 것 |
|---|---|
| `test_redact.py` | 개인정보 가리기, 남겨야 할 기관 정보·납부번호 |
| `test_account.py` | 납부용 계좌는 남기고 환급·본인 계좌는 가리기 |
| `test_verify.py` | 정방향·역방향 검증, 모양만 다른 같은 값 (120,000원 = 12만 원) |
| `test_agent.py` | 도움 고르기, 문의 문장, 일정 파일(.ics) 형식 |
| `test_stream.py` | 변환 도중 오류가 나면 반쪽 결과를 남기지 않기 |
| `test_qa.py`, `test_app_qa.py` | 묻고 답하기 (코드, 화면) |
| `test_saved_results.py` | 예전 결과에 잘못된 경고가 없는지 (samples 폴더가 있을 때만) |

## 배포

GitHub `main` 브랜치에 push하면 Streamlit Community Cloud가 자동으로 다시 배포합니다.
앱 설정의 **Secrets** 칸에 `ANTHROPIC_API_KEY`와 `APP_PASSWORD`를 `secrets.toml`과 같은 형식으로 넣습니다.

## 폴더 구조

```
easy-korean/
├── app.py               # 웹 화면 (입장 비밀번호, 탭, 결과, 도움 버튼, 질문 대화)
├── pipeline.py          # 화면과 터미널이 함께 쓰는 처리 흐름
├── image_prep.py        # 사진 준비 (HEIC 변환, 회전, 크기 줄이기)
├── transcribe.py        # 사진에서 글자 읽기 (이름·주소 표시 포함)
├── mark_personal.py     # 글 입력용 이름·주소 찾기
├── redact.py            # 개인정보 가리기 (코드 규칙)
├── simplify.py          # 쉬운 한국어 변환 (스트리밍)
├── verify.py            # 원문 대조 검증 (정방향·역방향)
├── agent.py             # 도움 고르기 (일정·문의·준비물)
├── qa.py                # 묻고 답하기
├── convert.py           # 터미널용 변환
├── test_connection.py   # API 연결 확인
├── prompts/             # AI 규칙서 (rules.txt = 쉬운 한국어 변환 규칙)
├── tests/               # pytest 테스트 (가짜 AI 응답)
├── .streamlit/          # 화면 설정(config.toml), 비밀 설정 예시
├── requirements.txt     # 실행용 라이브러리
└── requirements-dev.txt # 테스트용 라이브러리
```

## 사용한 기술

| 구분 | 사용한 것 |
|---|---|
| 언어 · 화면 | Python, Streamlit |
| AI | Claude API: 글자 읽기·변환은 `claude-sonnet-5`, 도움 고르기·묻고 답하기는 `claude-haiku-4-5` |

| 테스트 | pytest |
| 배포 | Streamlit Community Cloud |

## 개인정보와 안전

- 서버에 사진·원문·결과를 저장하지 않습니다. 결과는 사용자가 직접 내려받습니다.
- 사진과 글은 변환을 위해 AI 서비스(Claude API)로 전송됩니다. 화면에도 이렇게 안내합니다.
- 주민번호·휴대폰·카드·계좌는 코드 규칙으로, 이름·주소는 AI 표시와 이름표 규칙으로 두 번 가립니다.
- 질문도 가린 뒤 AI로 보냅니다.
- 문서 안에 지시처럼 보이는 글이 있어도 따르지 않습니다.

## 알려진 한계

- 역방향 대조는 날짜·금액·번호만 확인합니다. AI가 지어낸 일반 단어나 문장은 규칙서에 의존합니다.
- 시간, 장소, 숫자 없이 한글로만 쓴 금액(예: 십이만 원)은 자동 검증하지 않습니다.
- 이름표 없이 적힌 이름·주소는 AI 표시에만 의존합니다.
- 조건이 붙은 기한은 "경우", "해당자", "해당하는 분"이라는 말로만 판단합니다.
- 캘린더 일정은 하나만 만들고, 안드로이드에서는 일정 파일이 바로 캘린더에 들어가지 않을 수 있습니다.

더 자세한 개발 규칙과 한계는 [`CLAUDE.md`](CLAUDE.md)에 있습니다.
